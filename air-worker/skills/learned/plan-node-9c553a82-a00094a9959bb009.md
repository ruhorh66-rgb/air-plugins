# Verify completion separately from judgment

## When to apply
When a plan-node run reports successful checks but its learning verdict is `unjudged` or the judge is not configured.

## Procedure
1. Record the run as technically verified only when the available validation, tests, vet checks, and relevant semantic smoke evidence pass.
2. Preserve the run ID and receipt reference for traceability.
3. Keep the learning verdict explicitly `unjudged` when the judge is not configured; do not treat successful checks as a judgment.

## Pitfalls
- Do not convert a technical PASS into a judged verdict.
- Do not claim a reusable lesson from evidence that lacks a configured judge.
