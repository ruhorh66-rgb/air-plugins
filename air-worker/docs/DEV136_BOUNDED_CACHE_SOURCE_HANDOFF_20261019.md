Каталоги читаются порциями по 128 записей; перед хешированием проверяются лимиты, физическая идентичность, size/mtime, Windows hardlink/reparse, перед и после — путь. При нарушении — fail closed. Совместимость канонического digest (сортировка путей, `rel + NUL + hex(SHA256(contents)) + NUL`) сохранена для штатных файлов. Symlink/junction DEV-136 отвергает более строго, чем общая функция.
